# 音频与模拟网关验证

本轮依用户要求，不继续调摄像头、不接实体仪器，先完成真实收音和电脑控制台。
用户后续澄清，笔记本测试指以后用实体笔记本插线接板子；已写的网络模拟器作为可选工具保留。
**本轮没有在另一台实体笔记本上安装软件，没有验证实体笔记本经 USB 扮演仪器。**

## 最终版本与环境

实物微雪 ESP32-P4-NANO，P4 rev 3.1，16 MB Flash，32 MB PSRAM，CH343 COM5。
当前固件 0.3.1，ESP-IDF 5.5.4、esp_wifi_remote 0.14.5、ESP-Hosted 1.4.6、esp_codec_dev 1.6.2。
板载 C6 出厂固件未改写。网关地址 192.168.2.38，电脑控制台 http://127.0.0.1:8765。
所有工具、缓存、日志、数据留在本项目目录；临时 P: 盘为本目录别名。

## 修复与边界

此前失败记录保留。新 Hosted 3.1 与原厂 C6 的接收缓冲契约不匹配，曾发生缓冲上界阻塞；
恢复厂家对应的 1.4.x 路线后，继续修复了模拟器普通网络重试错误更换会话的问题。
电脑丢提交响应时只查原请求，不重发写入；模拟器可幂等重传已有结果。
音频改用 PSRAM 中 256 帧、约 5.12 秒的有界缓冲，应对短时 Wi-Fi 等待。
掉线测试改为发送故障命令时立即开始观察，避免迟到确认遮住整个离线窗口。
验收程序记录失败项，不覆盖成成功，也不因一次查询失败丢掉后续证据。

当前仍有实测音频缺口，不能宣称无丢帧。三分钟通过不等于需求中建议的三十分钟已通过。
真实 USB Host、Hub、仪器协议、真实电机、联合音视频、精密跨仪器同步均未验证。
有界去重范围和重启行为见《网关与音频协议》，不是永久 exactly-once。
