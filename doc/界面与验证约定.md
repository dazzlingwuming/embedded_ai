# BenchLink 本地测试台

视觉方向：浅色、克制的实验台，波形作为主工作区，清晰的状态和数据来源优先。
内容顺序：连接与采样状态 → 真实麦克风波形/频谱和录音 → 模拟仪器与命令 → 测试记录。
交互方向：按钮明确反馈运行状态；曲线只在有数据时更新；支持键盘、窄屏和减少动态效果。

采用 UI/UX 搜索中与仪器工作台匹配的 Minimalism & Swiss Style 方向；
不采用搜索返回的营销落地页结构。使用系统中文字体与等宽数字，不依赖外部字体或图片。
真实采集使用青绿色，模拟数据使用带文字说明的琥珀色，不单靠颜色区分来源。

当前范围为本地原型。笔记本可运行网络仪器模拟器；不能以软件模拟结果证明实体 USB
设备、Hub、示波器或电机已经接入。当前联合固件提供真实摄像头、麦克风和喇叭，
语音问答使用单独的处理通路；原始测量 WAV 保留采样率、固定增益和未经语音算法处理的内容。
