# 用笔记本模拟仪器

这份程序只需要 Python 3.10 或更新版本，没有第三方依赖。
笔记本和开发板连接同一局域网即可，局域网不必能上互联网。

1. 在电脑控制台点击「停止模拟器」，避免两台电脑使用同一组设备 ID。
2. 将 `instrument.py` 复制到笔记本的一个目录。
3. 在那个目录打开终端，运行：

```powershell
python instrument.py --board http://192.168.2.38 --devices 4
```

Windows 也可以使用 `py -3 instrument.py ...`；开发板 IP 变化后修改 `--board`。
程序每五秒输出连接状态，按 Ctrl+C 停止。它不监听笔记本端口，也不需要安装驱动。

主电脑打开本机控制台，在「仪器通信」选择 `sim-01` 到 `sim-04`，
查询身份、读取状态、读取波形，或者修改模拟参数。不要同时再启动控制台内置模拟器。

通信路径确实经过开发板：主电脑 → Wi-Fi → ESP32 网关 → Wi-Fi → 笔记本 → 原路返回。
波形由笔记本生成，调整 amplitude 后再次读取波形可以观察幅度变化。
amplitude 范围 0～5，frequency_hz 范围 1～2000，offset 范围 -2～2；
这些只属于虚拟仪器，不能套用为真实电机的允许参数。

普通笔记本的 USB 接口通常作为主机，不能仅用一根普通 USB 线把它伪装成 USB 仪器。
本程序验证网络通信、命令状态和记录流程；真实 USB Host、Hub 和仪器驱动仍需实物验证。
